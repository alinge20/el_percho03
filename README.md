# El Percho — Catálogo E-Commerce

Catálogo web para tienda de ropa con categorías variadas, carrito de compras funcional y diseño responsivo.

## Características

- Catálogo de productos con imágenes y precios en pesos colombianos
- Filtro por categorías: Mujer, Hombre, Accesorios
- Carrito de compras lateral con:
  - Agregar y eliminar productos
  - Modificar cantidades (+/-)
  - Total automático
- Animaciones al agregar productos
- Diseño responsivo (móvil y escritorio)
- Interfaz moderna con tipografía elegante

## Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Variables CSS)
- JavaScript (Vanilla)
- Google Fonts (Playfair Display + Inter)

## Uso

Abrir `index.html` en cualquier navegador. No necesita servidor.

## Estructura

```
el_percho03/
├── index.html      # Página principal
├── styles.css      # Estilos
├── app.js          # Lógica del carrito y filtros
└── README.md
```
